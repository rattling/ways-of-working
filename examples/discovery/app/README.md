# Brightwater App 🔥

Built by Jordan over the summer with an AI assistant. Open `index.html` in a browser. No install needed!

## Features

- ✅ Secure login for staff and admin
- ✅ Dashboard with live charts (jobs, revenue, engineers)
- ✅ Customer booking portal with deposits
- ✅ Live van tracking map
- ✅ Digital job sheets that send straight to the office spreadsheet
