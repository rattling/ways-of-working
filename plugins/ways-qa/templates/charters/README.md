# Charters

One file per exploratory session: what to explore, with what, to find out what. Write it before the session, and add what you found after.

```markdown
# Explore <area> with <resources or persona> to discover <what you want to learn>

**Time box:** 45 minutes
**Environment:** beta

## Found
- 

## Filed
- #
```

What turns up becomes an issue, then `/ways-qa:triage`, and, for a bug, `/ways-qa:reproduce`.
